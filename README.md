# Труба

Оболочка m.youtube.com на системном WebView (Chromium) для Android 8.0+.

- **Без рекламы**: реклама вырезается из ответов YouTube (adPlacements/playerAds/adSlots),
  рекламные карточки скрываются, рекламные и трекинговые домены блокируются;
  если видеореклама всё же проскочила — она проматывается без звука и пропускается.
- **Фоновое воспроизведение**: звук продолжается при свёрнутом приложении и выключенном экране;
  медиа-уведомление, экран блокировки, кнопки гарнитуры; пауза при отключении наушников и звонке.
- **Картинка в картинке** (по желанию): при сворачивании во время воспроизведения видео уходит в окно
  с кнопками −10 с / пауза / +10 с.
- Открывает ссылки youtube.com / youtu.be и пункт «Поделиться».

Настройки: долгое нажатие на иконку → «Настройки» (или «Сведения о приложении» → шестерёнка).

## Сборка

Без Gradle (Linux): `ANDROID_JAR=/путь/android-34/android.jar ./build.sh` → `build/truba.apk`
(нужны пакеты `aapt dalvik-exchange zipalign apksigner` и JDK).

Или откройте папку в Android Studio — есть `build.gradle`.

`release.keystore` — ключ подписи (пароль `truba123`). Сохраните его: обновления, подписанные
другим ключом, не встанут поверх установленной версии.

## Где что

- `app/src/main/assets/inject.js` — всё, что делается на странице (реклама, фон, пульт, PiP).
- `Net.java` — блок-лист и внедрение скрипта в HTML до запуска скриптов YouTube.
- `MainActivity.java` — WebView, полноэкранный режим, PiP.
- `PlaybackService.java` — фоновый сервис, уведомление, MediaSession, аудиофокус.

Отладка: на ПК в Chrome откройте `chrome://inspect` при подключённом по USB телефоне.
