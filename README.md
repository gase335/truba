# Труба / Трубочка

Оболочка m.youtube.com на системном WebView (Chromium). Две версии из одного кода:

| | **Труба** (`full`) | **Трубочка** (`lite`) |
|---|---|---|
| Android | 8.0+ | 7.0+ |
| Пакет | `ru.gase.truba` | `ru.gase.truba.lite` |
| Без рекламы | ✓ | ✓ |
| Мини-плеер, шортс с возвратом к видео | ✓ | ✓ |
| Скорость, таймер сна, настройки | ✓ | ✓ |
| Фоновое воспроизведение, уведомление | ✓ | — |
| Картинка в картинке | ✓ | — |

Версии ставятся рядом друг с другом.

## Как пользоваться

- Открыли видео — оно разворачивается поверх ленты. **⌄** в шапке или «Назад» — свернуть в мини-плеер,
  лента остаётся доступной. Нажатие на мини-плеер — развернуть, **✕** — закрыть.
- Шортс, каналы и поиск открываются в ленте; видео в мини-плеере на это время встаёт на паузу
  и продолжается при разворачивании.
- **⋮** в шапке плеера: свернуть, картинка в картинке, скорость, таймер сна, настройки.
- **⚙** в шапке ленты — настройки приложения.

## Устройство

Два WebView: `browse` (лента) и `player` (видео). В обе страницы до запуска скриптов YouTube
внедряется `app/src/main/assets/inject.js` — он вырезает рекламу, разводит ссылки по окнам,
добавляет кнопки в шапку, управляет плеером.

- `MainActivity.java` — окна, мини-плеер, полноэкранный режим, меню плеера, PiP.
- `Net.java` — блок-лист и внедрение скрипта в HTML.
- `PlaybackService.java` — фоновый сервис, уведомление, MediaSession (только `full`).
- `Pip.java` — картинка-в-картинке (только `full`).
- `SettingsActivity.java`, `Prefs.java` — настройки.
- `app/src/full`, `app/src/lite` — отличия версий (`Flavor.java`, манифест, имя, иконка).

## Сборка

Android Studio: открыть папку, выбрать вариант `fullRelease` или `liteRelease`.

Без Gradle (Linux):
```
sudo apt install aapt dalvik-exchange zipalign apksigner openjdk-17-jdk python3
ANDROID_JAR=/путь/android-34/android.jar ./build.sh        # обе версии → build/truba.apk, build/trubochka.apk
./build.sh lite                                            # только одну
```
Ключ подписи — `release.keystore` (не в репозитории, пароль `truba123`). Храните его отдельно:
обновление, подписанное другим ключом, не встанет поверх установленной версии.

Отладка: `chrome://inspect` в Chrome на ПК при подключённом по USB устройстве.
